Request / Data Flow

1
User sets filters
Time Period, Warehouse, Category, Order Status — bound to reactive ref()s in a shared composable.
2
Vue view calls client/src/api.js
Centralized axios client builds query params and calls the matching endpoint.
3
FastAPI route handler filters in-memory data
server/main.py applies warehouse/category/status/month filters over lists loaded from JSON.
4
Pydantic validates the response
Each endpoint declares a response_model, enforcing shape before serialization.
5
Vue stores raw data, derives the rest
Raw API results sit in refs (allOrders, inventoryItems); totals and chart data are computed() from them.
